FILTERING CRITERIA (Bid/No-Bid Decision)
================================================================================

BID IF:
✓ Contract value: USD 50K - 5M (sweet spot for Datacraft)
✓ Technology stack: Match with Datacraft capabilities
✓ Geography: Kenya/East Africa preferred, but open to all
✓ Client type: Government, MDB, UN, large NGO
✓ Timeline: Sufficient time for quality proposal (2+ weeks preferred)
✓ Requirements: Clear scope, well-defined
✓ Competition: Reasonable (not 100+ expected bidders)

DO NOT BID IF:
✗ Contract value: < USD 20K (too small) or > USD 20M (too large for solo)
✗ Technology: Outside core competencies
✗ Eligibility: Restricted to specific countries/regions (if Datacraft excluded)
✗ Timeline: Insufficient preparation time (< 1 week)
✗ Requirements: Vague, unclear, or constantly changing
✗ Red flags: Unrealistic timelines, suspicious terms, payment concerns

================================================================================
COMMON ISSUES AND SOLUTIONS
================================================================================

ISSUE: Portal structure changed, scraper broken
SOLUTION: Check error logs, update parser, implement structure monitoring

ISSUE: Too many irrelevant tenders flagged
SOLUTION: Refine keywords, add negative keywords, implement ML scoring

ISSUE: Registration taking too long
SOLUTION: Parallel registrations, use aggregators as backup

ISSUE: CAPTCHA blocking automated access
SOLUTION: Rate limiting, user-agent rotation, consider commercial API

ISSUE: Authentication failures
SOLUTION: Refresh sessions regularly, implement token management

ISSUE: Opportunity overload (too many to bid on)
SOLUTION: Stronger filtering, focus on high-value tenders (USD 200K+)
